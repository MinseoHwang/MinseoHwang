# 넥서스원 | 검사 프로그램에 AI 추론 연결

[프로필로 돌아가기](../README.md)

웨이퍼 결함 이미지 분류 모델을 실험하고 C++/MFC 검사 프로그램과 연결했습니다. 입력 이미지의 전처리부터 기존 검사 정보와 추론 결과를 함께 기록하는 과정까지 다뤘습니다.

## 학습 데이터와 전처리

결함 이미지와 라벨을 정리하고, 중복 이미지 탐색과 crop·letterbox·색상 정규화를 다뤘습니다. 클래스 불균형에 대응하기 위해 가중치, 샘플링, 손실 함수와 증강 방법을 실험했습니다. 전이학습 모델을 비교하고 클래스별 결과와 CAM을 확인했습니다.

## 기존 검사 정보와 추론 결과 연결

모델의 분류 결과가 기존 검사 정보와 함께 사용되어야 했습니다. 클라이언트에서 전달한 CSV·이미지 경로를 받아 배치 추론하고, 기존 CSV 메타데이터를 보존하면서 분류 결과와 확률을 기록하는 흐름을 다뤘습니다.

```text
검사 프로그램 → CSV·이미지 경로 전달 → 전처리·배치 추론
                                      ↓
                   기존 CSV 정보 유지 + 분류 결과·확률 기록
```

ONNX Runtime을 검사 프로그램에 연결하면서 모델 출력의 logits와 확률을 구분하고, CPU·GPU 추론 호출을 연동했습니다. 결과를 기록할 때 기존 검사 정보가 사라지지 않는 것이 중요한 연동 조건이었습니다.

## 추론 형식 변환과 시간 측정

PyTorch 모델을 ONNX와 TensorRT FP16으로 변환하고 추론 호출 시간을 측정했습니다. 측정은 특정 실험 환경의 호출 시간을 대상으로 했으며, 검사장비 전체 처리량이나 양산 정확도를 입증하는 결과로 사용하지 않습니다.

## 범위

이 문서는 수행한 업무를 요약한 설명입니다. 회사 소스·원본 이미지·내부 발표자료는 포함하지 않았습니다. 모델 실험과 프로그램 연동 경험을 다루며, 모든 실험 모델의 양산 적용이나 고객 검수 완료를 의미하지 않습니다.
