# Remy | 티켓 예약·결제의 상태 관리

[프로필로 돌아가기](../../README.md)

| 주요 기술 | Java 21, Spring Boot, PostgreSQL, Spring Data JPA, JdbcTemplate |

## 본인 기여와 사례 범위

본인 작성 이력이 확인된 변경은 실시간 계좌결제 확장, 고객·관리자 환불 진입점 연결, 관리자 대사 상태 표시입니다. 카드와 실시간 계좌결제가 공통 승인·조회·환불 흐름을 사용하도록 확장하는 데 기여했습니다.

아래 복구 worker와 환불 재고 정책은 프로젝트에서 확인한 구현을 설명합니다. 모든 구성요소를 단독 설계·구현했다는 의미는 아닙니다.

## 결제수단 확장

실시간 계좌결제를 기존 승인·조회·환불 구조에 연결했습니다. 응답의 주문번호·금액·결제수단을 저장된 요청과 대조하고, 계좌번호는 표시용 마스킹 값으로 변환합니다. 빌링키는 결제 결과 객체에서 제외합니다.

입금 시점이 불확실한 가상계좌를 추가하면 재고 선점 만료 후 입금되는 상황까지 다뤄야 합니다. 프로젝트의 ADR은 실시간 계좌결제를 먼저 지원하고 비동기 입금은 보류하는 결정을 기록합니다.
