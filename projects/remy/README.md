# Remy 해외축구 VIP 티켓 판매 사이트

[프로필로 돌아가기](../../README.md)

해외축구 VIP 티켓 판매 사이트의 Java·Spring Boot 백엔드 개발에 참여했습니다. 실시간 계좌결제를 기존 승인·조회·환불 구조에 연결하고, 외부 응답의 확인과 고객·관리자 환불 진입점을 다뤘습니다.

| 항목 | 내용 |
| --- | --- |
| 역할 | 백엔드 개발 참여 |
| 주요 기술 | Java 21 · Spring Boot · PostgreSQL · Spring Data JPA · JdbcTemplate |
| 소스 | 비공개 · 설계와 처리 흐름 설명 |

## 본인 기여

- 실시간 계좌결제가 기존 승인·조회·환불 흐름을 사용하도록 확장했습니다.
- PG 응답의 주문번호·금액·결제수단을 저장된 요청과 대조하고, 계좌번호를 표시용 마스킹 값으로 변환했습니다. 빌링키는 결제 결과 객체에서 제외했습니다.
- 고객·관리자 환불 진입점을 공통 처리에 연결하고 관리자 대사 상태 표시에 기여했습니다.

입금 시점이 불확실한 가상계좌를 추가하면 재고 선점 만료 후 입금되는 상황까지 다뤄야 합니다. 프로젝트의 ADR은 실시간 계좌결제를 먼저 지원하고 비동기 입금은 보류하는 결정을 기록합니다.

## 프로젝트의 결제 상태 설계

결제 요청과 응답 사이의 통신 실패는 실제 결제 실패와 다릅니다. 아래 사례는 프로젝트에서 확인한 복구·재고 처리 구조입니다. 위 본인 기여와 구분해 설명합니다.

| 상황 | 처리 선택 | 상세 |
| --- | --- | --- |
| 승인 요청 후 응답 유실 | 결과 불명 상태를 보존하고 재승인 대신 거래 조회 | [결제 조회와 복구](payment-recovery.md) |
| 현지 티켓 확보 실패 후 환불 | PG 취소 확인 후 총량과 판매·선점 수량을 함께 조정 | [환불과 재고](refund-inventory.md) |

## 외부 응답 계약 검증

2026.11.04 모의 HTTP 테스트 `PaypleClientImplTest` 15개가 통과했습니다. 계좌 응답·마스킹, 다른 주문·결제수단의 응답 거절, 불명확한 응답, 취소 상태·잔액을 확인한 범위입니다.

PostgreSQL 동시성·생명주기 통합 테스트는 소스를 검토했으며 해당일 Docker 엔진 연결 불가로 재실행하지 못했습니다. 모의 HTTP 테스트 통과를 실제 PG 거래나 재고 DB 정합성 검증으로 확대하지 않습니다.
