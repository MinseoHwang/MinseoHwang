# Melpik 의류 대여 서비스

[프로필로 돌아가기](../../README.md)

TypeScript·NestJS 기반 의류 대여 서비스 개발에 참여했습니다. 이용권을 취소할 때 사용 회차를 올바르게 복구하는 문제와 상품 수집·검수·적재 흐름을 다룹니다.

| 항목 | 내용 |
| --- | --- |
| 주요 기술 | TypeScript · NestJS · TypeORM · MySQL · Python · Playwright · SQLite |
| 참여 영역 | 이용권 차감·취소 복원, 상품 데이터 처리 |
| 소스 | 비공개 |

## 취소 시 실제 사용한 이용권을 기준으로 복구

마지막 회차를 사용한 예약을 취소할 때, 횟수 소진과 수동 종료·만료를 같은 상태로 취급하면 복원 대상이 어긋납니다. 이용기간별 차감 묶음과 사용한 이용권을 기록하고, 취소 시 잔여 회차·유효기간·종료 기록으로 복구 대상을 판단하는 흐름을 다뤘습니다.

현재 상품 정보로 사용량을 추측하지 않고 실제 사용 이력을 기준으로 복구합니다. 이미 취소한 요청은 다시 복원하지 않도록 상태를 검사합니다. 후속 로컬 구현 전체를 개인 단독 기여로 묶지 않습니다.

## 중단 후 이어 가는 상품 수집

4개 의류 사이트의 목록·상세 작업을 나누고 SQLite에 상태와 시도 횟수를 저장합니다. 목록 완료와 다음 상세 작업 등록을 함께 저장해 중단 시 작업 누락을 줄이고, 재개할 때 완료 작업은 보존합니다.

일시 오류는 정해진 횟수만 재시도하고 식별 충돌·품번·색상 등 반복 오류는 검토 대상으로 분리합니다. 모델 판단 인터페이스는 재시도와 사람 검토로 제한했으며, 보관된 실행은 규칙 모드·모델 호출 0회입니다.

## 검수한 상품만 적재

상품명이 달라도 같은 상품을 식별할 수 있도록 브랜드·품번·색상을 기준으로 데이터를 처리합니다. 공통 품번 규칙을 Python·TypeScript에서 공유하고, 사진 검수 승인 정책을 거쳐 적재합니다. 수집 성공과 상품 등록 가능 여부를 별도 단계로 다룹니다.

## 검증과 남은 문제

| 검증 | 결과와 범위 |
| --- | --- |
| 크롤러 테스트 | 2026.11.04 원본·보관 사본 각각 58개 통과 |
| 백엔드 선별 테스트 | 83개 중 82개 통과·1개 실패 |
| 관리자 실측·소재 화면 | 9개 통과 |
| 과거 상품 등록 검증 | 2026년 가을·겨울 대상 1,412건 · 현재 운영 DB 재집계 아님 |

백엔드 실패 1건은 첫 구독 결제 거절 후 상태에 관한 차이입니다. 테스트는 결제 대기를 기대하지만 구현은 취소·재고 복구로 처리하므로 정책 확인 후 양쪽을 맞춰야 합니다.

수집 보고서는 검토 작업이 남은 `REVIEW_REQUIRED` 상태입니다. 등록 검증 건수를 실제 거래량으로, 모의 응답 테스트를 실결제·현재 운영 배포 검증으로 해석하지 않습니다.
