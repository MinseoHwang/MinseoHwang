# AutoUpload | 콘텐츠 제작·승인·게시 워크플로

[프로필로 돌아가기](../../README.md)

LLM 콘텐츠 제작과 검수·승인·예약 게시를 연결하는 Python 자동화 프로젝트입니다. 생성한 글을 승인한 그대로 게시하고, 중단된 작업을 이어 가며, 외부 API 응답이 불확실할 때 상태를 보존하는 흐름을 다룹니다.

**기술:** Python, LangGraph, SQLite, HTTPX, Pillow, OpenCV.

아래 내용은 2026.11.04 확인한 로컬 프로젝트 구현과 테스트 범위입니다. 기능 전체의 단독 개발이나 현재 운영 배포 일치를 의미하지 않습니다.

## 제작 중단·재개

LangGraph와 SQLite 체크포인트로 제작 단계를 연결합니다. 성공 응답 캐시와 역할별 호출 기록을 이용해 재개 시 성공한 단계의 결과를 재사용하고, 호출 예산을 제한합니다.

## 승인한 내용과 실제 게시 내용의 일치

승인할 때 콘텐츠·이미지 해시와 대상 계정을 고정합니다. 승인 이후 내용이 달라지거나 승인이 없는 작업은 예약·게시하지 못하도록 검사합니다. SQLite 트랜잭션과 조건부 상태 전이로 중복 작업을 제어합니다.

## 게시 결과가 불확실할 때

게시 API가 타임아웃되어도 원격 게시가 실패했다고 단정할 수 없습니다. `uncertain` 상태와 작업·컨테이너 정보를 보존하고 결과를 확인합니다. 무조건 재게시하는 흐름과 구분되며, 분산 환경의 정확히 한 번 실행을 보장하는 구조는 아닙니다.

## 검증 기록과 남은 문제

2026.11.04 사본 테스트 222개 중 **208개 통과, 2개 실패, 11개 오류, 1개 제외**였습니다.

- 승인 전 게시 차단, 승인 후 내용 변경 차단, 중복 worker 제어, 게시 타임아웃 처리, 체크포인트 재개 관련 테스트가 통과했습니다.
- 실패 2개는 콘텐츠 정책과 테스트 기대의 불일치입니다.
- 오류 11개는 Windows에서 사용 중인 임시 SQLite 파일을 정리하다 발생했습니다.
- 제외 1개는 Linux 파일 잠금 테스트입니다.

모의 제공자·합성 이미지 기반 검증이며 실제 모델·게시 API·AWS 호출은 포함하지 않았습니다. 과거 운영 기록에는 수동 개입이 있어 완전 무인 운영이나 마케팅 성과로 표현하지 않습니다.
