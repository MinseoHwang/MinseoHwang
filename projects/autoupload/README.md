# 해외축구 이슈·유소년 홍보용 인스타그램 자동 업로드

[프로필로 돌아가기](../../README.md)

해외축구 이슈 콘텐츠와 유소년 홍보 콘텐츠의 제작·검수·승인·인스타그램 업로드를 연결하기 위한 Python 자동화 프로젝트입니다. 게시 전 사람이 확인하고, 승인한 내용과 실제 게시할 내용이 일치하는지 검사하며, 중단된 제작 작업을 이어 가는 흐름을 다룹니다.

| 항목 | 내용 |
| --- | --- |
| 내부 프로젝트명 | AutoUpload |
| 주요 기술 | Python · LangGraph · SQLite · HTTPX · Pillow · OpenCV |
| 대상 업무 | 콘텐츠 제작·검수·승인·예약 게시와 게시 결과 확인 |

## 승인한 콘텐츠와 실제 게시할 콘텐츠 연결

승인 후 글이나 사진이 바뀌면 검토하지 않은 내용이 게시될 수 있습니다. 승인 시 콘텐츠·이미지 해시와 대상 계정을 고정하고, 내용이 달라지거나 승인이 없는 작업은 예약·게시하지 못하도록 검사합니다. SQLite 트랜잭션과 조건부 상태 변경으로 중복 작업을 제어합니다.

```text
이슈·홍보 소재 → 콘텐츠 제작 → 사람 검수·승인 → 예약·게시 → 결과 확인
                    │                │
                    └─ 중단 후 재개  └─ 승인 내용·이미지·계정 검사
```

## 제작 작업 중단 후 재개

LangGraph와 SQLite 체크포인트로 제작 단계를 연결합니다. 재개 시 성공한 단계의 결과를 재사용하고, 역할별 호출 기록과 예산으로 반복 호출을 제한합니다.

## 게시 요청의 타임아웃과 실패 구분

인스타그램 게시 API가 타임아웃되어도 원격 게시가 실패했다고 확정할 수 없습니다. `uncertain` 상태와 작업·컨테이너 정보를 보존해 결과를 확인합니다. 분산 환경의 정확히 한 번 실행을 보장하는 구조로 설명하지 않습니다.

## 검증과 남은 문제

2026.11.04 사본 테스트 222개 중 **208개 통과·2개 실패·11개 오류·1개 제외**였습니다.

- 승인 전 게시 차단, 승인 후 내용 변경 차단, 중복 worker 제어, 게시 타임아웃 처리와 체크포인트 재개 관련 테스트가 통과했습니다.
- 실패 2개는 유소년 학습점 필드를 기대하는 테스트와 당시 해외축구 팬용 콘텐츠 설정의 불일치입니다. 프로젝트의 홍보 목적과 별개로, 현재 콘텐츠 정책에 맞춰 설정·테스트를 정리해야 합니다.
- 오류 11개는 Windows의 사용 중인 임시 SQLite 파일 정리 과정에서 발생했습니다. 제외 1개는 Linux 파일 잠금 테스트입니다.

모의 제공자·합성 이미지로 처리 흐름을 확인한 결과이며 실제 모델·인스타그램·AWS 호출을 포함하지 않습니다. 과거 운영에는 수동 개입이 있었고, 이 수치를 완전 무인 운영이나 홍보 효과로 제시하지 않습니다. 기능 전체의 개인 단독 개발과 현재 배포 상태의 일치는 별도 범위입니다.
